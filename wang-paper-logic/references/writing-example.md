# 写作示例

**论文：**Haobo Wang 等，*PiCO+: Contrastive Label Disambiguation for Robust Partial Label Learning*，*IEEE Transactions on Pattern Analysis and Machine Intelligence*，46(5):3183–3198，2024。[DOI: 10.1109/TPAMI.2023.3342650](https://doi.org/10.1109/TPAMI.2023.3342650)；[arXiv 记录](https://arxiv.org/abs/2201.08984)。

源仓库根目录提供 `writing_example.pdf`；上述 DOI 和 arXiv 链接也可用于阅读。

阅读时重点分析**主张之间的关系**：

> **示例分析：PiCO+ 的写作主线**
>
> 1. 开头先将标签歧义说明为读者能理解的问题，再指出表征学习和标签消歧之间的张力。
> 2. 核心方法让两个组件相互促进。方法总览先讲二者的关系，再进入具体步骤。
> 3. 理论与实验部分回到这条相互促进的主线，说明结果如何支持主张。
> 4. 带噪标签设定和 PiCO+ 扩展提供进一步贡献，并与原有主线相连。

借鉴一篇论文时，关注它怎样安排问题、方法和证据；分析用户的论文时，结合相应章节或图表说明某种写法的作用。
